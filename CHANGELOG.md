# Changelogs

Drafts for the mod pages. Each section is the text to paste for that mod's release.

## Translocator Locator (Command) 2.0.1

- Chat output now shows compass directions (N, NE, E, SE, S, SW, W, NW) instead of arrow characters, which showed up as empty squares in some fonts.
- Fixed Translocator Locator and Translocator Navigator overwriting each other's saved data. Both mods share one save file, and whichever saved last used to discard what the other had recorded. Saves now merge with what is on disk and are written safely.
- Updated for Vintage Story 1.22.7.

## Translocator Navigator 2.0.1

- /pathtl "Next" now shows a compass direction (N, NE, E, SE, S, SW, W, NW) instead of an arrow character that rendered as an empty square.
- /pathtl "Full Path" now separates steps with "to" instead of a symbol that did not render.
- Fixed Translocator Locator and Translocator Navigator overwriting each other's saved data (translocators you had seen, and your last path). Saves now merge with what is on disk.
- Updated for Vintage Story 1.22.7.

## Translocator Repair 1.1.0

- Repairing is now a block behavior instead of a replacement block class, so it no longer conflicts with other mods that change the translocator's class. Behavior is unchanged: right click an unrepairable translocator with cupronickel rods (3, or 1 as a Clockmaker).
- Updated for Vintage Story 1.22.7.

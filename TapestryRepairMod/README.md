# GildedChronicles - Tapestry Repair

Adds the **temporal loom**, a Jonas device (1 block wide, 1.5 tall) powered by temporal gears. It weaves flax twine into glowing blue-green **temporal fiber**, which you craft into a **temporal sewing kit** that weaves time back into ruined (rotten) tapestries. Required on both client and server.

**The temporal loom** (right-click it with):
- a **temporal gear**: powers the loom, 16 charges per gear (it holds up to 64);
- **flax twine**: loads it with twine (up to 64);
- an **empty hand**: takes the finished temporal fiber.

While it has both twine and charge it weaves one temporal fiber from one flax twine and one charge every 3 seconds. Look at it to see its twine, charge and fiber.

**Crafting** (grid):

- Temporal loom (3×3), from Jonas parts and a temporal gear:

  | | | |
  |---|---|---|
  | Spring frame | Temporal gear | Cylinder (Jonas part) |
  | Cupronickel rod | Gears frame | Cupronickel rod |
  | Lead plate | Metal parts | Lead plate |

- Temporal sewing kit (1×2): 1 temporal fiber and 1 stick (fiber over stick).

**Repairing:** hold the temporal sewing kit and right-click a ruined tapestry. Each repair uses 1 of the kit's 3 uses (nothing in creative mode). Looking at a ruined tapestry shows the repair hint, and the interaction help shows the sewing kit.

**The unraveling loom** is the temporal loom's inverse. It works the same way but runs on **rusty gears** and unravels flax twine into dark **decayed fiber**. Craft 1 decayed fiber with 1 stick into a **temporal decay kit** (3 uses): hold it and right-click a tapestry to make it rotten (nothing is used in creative mode). A temporal sewing kit repairs it again.

- Unraveling loom (3×3): the same pattern as the temporal loom, with a rusty gear in place of the temporal gear.

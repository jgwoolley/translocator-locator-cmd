A client side mod that calculates the shortest path between your current position and a target, factoring in translocator jumps as "shortcuts."

The mod does this by waiting until you are directly looking at a translocator. Then it adds that translocator, and any connected translocator to the list.

Navigator window

Press Ctrl+T (rebindable under Controls as "Translocator Navigator") or type .tlnav to open the navigator window.

  • Enter a Start and a Destination in the coordinates the game shows, or press Here to use your current position.
  • Find route lists the route step by step (walk to a translocator, teleport, walk on) and shows how far the translocators save you. Copy puts a step's coordinates on the clipboard.
  • Start guidance shows the current step at the top of the screen, with the distance and direction from where you are, and an arrow beside it that points the way relative to where you look. It moves on by itself as you travel and through translocators, and tells you when you have arrived.

Commands

Description of the commands this mod adds.

Command Description
.tlnav Opens the navigator window. .tlnav stop stops the on-screen guidance.
.pathtl Find shortest path to coordinates using known translocators, by specifying an optional target location, and start location. Or will fall back to previous target location, and current player position.
.pathtlhist Find shortest path to coordinates using known translocators with the previously given start and target location. Fails if none found.
.counttl Counts the translocators seen by this mod within this world, as well as any others. Translocators are stored on the client system to prevent duplication.

A client side mod for VintageStory which allows you to find Translocators, and optionally, add them as waypoints. An XRAY for Translocators!

Command Description

This mod adds the following command to your game:

.findtl


If you give it an argument value of true, it will also add waypoints (default = false).

.findtl true

If you give a third argument, you can change the block range (default = 150).

.findtl false 150

There are also some commands for finding other blocks, each of them have the same arguments above:

Command Description
.findtl Finds nearby translocators.
.findtreasure Finds nearby treasure, and gears.
.findart Finds nearby tapestries, paintings, and chandeliers.
.findchest Finds nearby item containers.
.findsoil Finds nearby bony soil, and high fertility soil.
.findclay Finds nearby clay.
.findore Finds nearby ores, crystals, and marble.
.findbees Finds nearby bees.
.findresin Finds nearby resin.
.findplants Finds nearby mushrooms, reeds, bushes, and flowers.
.findfruit Finds nearby fruit trees.
.findmarble Finds nearby marble.

Other Commands

There are some other commands used mostly for debug purposes.

Command Description
.countwaypoints Counts the waypoints generated by this mod within this world, as well as any others. Waypoints are stored on the client system to prevent duplication.

Files

These files are used to store information that the mod needs to work. Please see the wiki page for VintagestoryData folder.

File Description
${DATA_PATH}/ModConfig/Nf3tConfig.json Stores common settings for all Nf3t mods.
${DATA_PATH}/ModData/Nf3tData.json Stores common data used for all Nf3t mods.

 

Adding Additional Commands

It is possible to add additional commands by editing the config file.

  1. You can add specific blocks you want to search for by specifying a prefix to the block code. Then you can specify the color of the chat message, as well as the waypoint. The icon can also be specified, you can look up the vanilla icon codes here. Then you can specify the keywords associated with this block. This will determine which commands this will be associated with, and you can specify more than one.
{
    "Selectors": [
        {
            "StartsWith": "tapestry",
            "Color": "blue",
            "Icon": "vessel",
            "Keywords": [
                "art",
                "treasure"
            ]
        }
    ]
}

2. Then you can specify the command you want to create. You'll want to give the command a name, which will be prefixed with a period (because it is a client command). The description text will be associated with the command. ClosestOnly is a flag that will tell the command only to return the closest block of each selector. This is to prevent blocks that appear in larger numbers from generating too many waypoints. The keyword is what associates the command with the selector.

{
    "Commands": [
        {
            "Name": "findtreasure",
            "Description": "Finds nearby treasure.",
            "ClosestOnly": false,
            "Keyword": "treasure"
        }
    ]
}

Allows players to duplicate Better Ruins blueprints (schematics) using parchment.

  • Requires Better Ruins
  • Put a sheet of parchment and a Better Ruins schematic in the crafting grid (in any order) to get a second copy of the same schematic
  • The original schematic is not used up, so you can copy a copy as often as you have parchment
  • A content-only mod: it adds one recipe and no code, so it is safe to add to or remove from an existing world

You know when you are watching a YouTuber explore a structure you have never seen before? If you can identify a few unique blocks, you can search for the structure that contains them.

  • Search the structures (schematics) used by world generation by block code or properties
  • Opens with Ctrl + Y by default; the key can be changed in the settings
  • For blocks such as tapestries, if you know anything about the block entity's attribute values, you can narrow the search further

Client-side only.

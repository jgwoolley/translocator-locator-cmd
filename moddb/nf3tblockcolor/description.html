Client-side utility that writes one representative color per block to a JSON file, for map making, palettes and tooling.

Run .blockcolors and the colors are saved to ModData/Nf3tBlockColors.json in the game's data folder, for example:

{
  "game:soil-medium-none": {
    "hex": "#6B5A45",
    "alpha": 255
  }
}

This file is also where the Vintage Story wiki (jgwoolley.github.io/vintage-story-wiki) gets the block colors of its schematic viewer.

  • Optional wildcard filter on the block code: .blockcolors game:rock-*
  • Blocks with no color texture (invisible or specially rendered blocks) are written as white (#FFFFFF)
  • The color is the game's own quick average of the block's color texture (the one used for the world map), not an exact mean of every pixel, and it ignores climate and season tinting

Server-side only mod that writes a line to the server log whenever world generation creates a new structure, with its code, group and bounding box:

[StructureLog] Generated structure 'code' (group: g) at (x1, y1, z1) to (x2, y2, z2)

Filtering is stored in ModConfig/nf3tstructurelog.json. In Denylist mode (default) everything is logged except matching structures; in Allowlist mode only matching structures are logged. Patterns are case-insensitive wildcards (*) that must match the whole structure code or its group, so use *ruin* rather than ruin.

Admins (the controlserver privilege) can change the filter in game, and changes apply immediately:

  • /structurelog list, mode allowlist|denylist, add, remove, set, clear
